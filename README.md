## Project Overview

This project predicts an individual's phone addiction level using behavioral, psychological, and smartphone usage patterns. The objective is to identify factors contributing to excessive smartphone dependency and develop a predictive machine learning model.

## Problem Statement

Excessive smartphone usage has become a growing concern, affecting mental health, productivity, sleep quality, and social interactions. Identifying users at risk of phone addiction can help organizations and individuals take preventive actions. This project uses machine learning techniques to predict addiction levels based on user behavior and usage patterns.

## Dataset Information

Dataset Size: 6,000 Records

## Why It Matters

Smartphone addiction has become a significant concern in modern society due to its impact on mental health, physical well-being, academic performance, and workplace productivity. Excessive phone usage can lead to anxiety, depression, sleep disorders, reduced concentration, and weakened social relationships. As smartphones become increasingly integrated into daily life, identifying individuals at risk of addiction is essential for promoting healthier digital habits. This project leverages machine learning to analyze behavioral and usage patterns, enabling early detection and intervention strategies. The insights generated can support educators, healthcare professionals, employers, and digital wellness platforms in fostering balanced technology use and improving overall well-being.

## How It Works

The system collects smartphone usage, behavioral, and psychological data from users.
The data is cleaned, transformed, and prepared using preprocessing techniques.
Machine learning models are trained to learn patterns associated with phone addiction levels.
The best-performing model is selected through evaluation and hyperparameter tuning.
Finally, the model predicts an individual's addiction level and provides insights for early intervention and digital well-being.
